# Ashide v0.0.7

## Omp 新建会话标题 & Cursor resume 修复

- **Omp 新建会话现在显示真实标题。** 新增 Ashide 内置 Omp extension（`ashide-omp.ts`），将 Omp 原生 `session_start` / `input` / `turn_end` 事件桥接为 Ashide 结构化 OSC 777 `warp://cli-agent` 协议。新建 Omp 会话的首条 prompt、session identity 和完成信号通过既有 `CLIAgentSessionsModel → title_like_text → pane title` 管道投影，左侧标签不再退化为 "Omp"。
- **Omp extension 自动安装。** `OmpPluginManager` 支持一键 auto-install，将内置 extension 写入 `~/.omp/agent/extensions/ashide-omp.ts`，与 Claude/OpenCode 的 auto-install 模式一致。
- **Cursor agent resume 不再失败。** Cursor transcript 文件名 UUID 不是 Cursor chat ID（后者来自 `~/.cursor/` 的 `store.db`，不是 `agent-transcripts` 文件 stem）。`can_resume` 设为 `false`，Session Navigator 仍显示 Cursor 历史标题/cwd 但不再提供会失败的 resume action。
- **Omp candidate classification（LR-205）。** Omp 顶层物理 JSONL 先经 shared classifier：合法 session header 进入可恢复集合；provider-native headerless diagnostic-only 文件排除；malformed header 仍 fail closed。Dev helper freshness 覆盖 shared parser 源码。
