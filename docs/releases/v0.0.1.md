# Ashide v0.0.1

Ashide 的全新首发版本：一个 local-first、agent-first 的终端与开发环境。此版本从新的仓库历史开始发布。

## 亮点

- 在 Session Navigator 中发现并恢复本地 CLI Agent 会话；发现和 Resume 彼此解耦，恢复使用各 provider 的原生命令。
- Jcode 会话发现遵循原生 picker 的默认可见性：跳过 self-dev/swarm debug worker 和空会话，且过滤结果不占用最近会话配额；Jcode 使用官方应用图标。
- 已支持的 native Resume 包括 `jcode --resume <session-id>` 与 `omp --resume <session-id>`；发现设置不会阻止直接 Resume。
- 本次发布提供 macOS 应用与 macOS/Linux remote helper、Linux CLI 资产和校验和。

## 平台范围

- macOS 与 Linux：本次构建、打包和发布。
- Windows：CI 构建、打包、checksum 与 installer 发布均为本次 Release 的必经 gate；暂不以 Windows 真机安装或 WSL 手工运行验证阻断发布。

## 已知边界

- 第三方 Agent 的 realtime attach/input/cancel、Fork/Edit/Write-back 和对原生会话文件的写入不属于本版本能力。
