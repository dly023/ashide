# Ashide v0.0.4

在 v0.0.3 基础上的修复版本，聚焦 Session Navigator Resume 标题稳定性、CLI Agent 会话发现边界，以及远程文件与 SSH 刷新生命周期。

## 修复

- **Resume 后保留扫描到的会话标题。** 扫描标题现在写入 pane 容器的 `custom_vertical_tabs_title`；live 投影不再使用 tab group、环境名或 shell/OSC 标题覆盖它。
- **收敛 Session Navigator 标题合并优先级。** live pane 的明确自定义标题优先；live 标题缺失或仅为通用 agent 名时，继续使用 indexed session 的具体标题。local 与 remote 使用同一规则。
- **远程编辑器 push 使用稳定索引。** Environment Runtime buffer 以 session binding、host 和 path 建立 O(1) 索引；同 host 的 session 变化不会把事件投递到错误连接，buffer 关闭时同步清理索引。
- **SSH catalog 刷新状态归一。** generation、intent、loading 与 error 由单一 refresh controller 持有；过期结果不能覆盖当前 committed catalog。

## 架构与性能

- CLI Agent JSONL 发现、解析、路径、策略与错误边界拆分为独立模块，保留共享的 local/remote discovery contract。
- 热路径/平行路径改写必须继承既有 ownership static gates，并由负向探针 fail closed，防止性能修复绕过标题、身份或生命周期所有权。
