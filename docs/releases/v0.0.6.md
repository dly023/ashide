# Ashide v0.0.6

## Session Navigator 与 Omp

- **会话列表搜索更快且可键盘完成。** Command Palette 的 Session Navigator 入口复用已发布的当前 Environment 投影做增量搜索；侧栏搜索支持稳定的 cursor / `Down` 键导航，不再把未提交的 discovery 结果临时混入 UI。
- **Environment provider picker 完整收口。** 打开、过滤、键盘选择、确认与关闭均由 Workspace lifecycle owner 管理；picker 关闭后迟到的 `EditorEvent::Edited` 会 fail-closed，不能重新写回查询、selection 或 alias。
- **本机多窗口 discovery 合并。** 相同 source scope 与 provider 集合的本机扫描在进程级合并；显式刷新仍能安全抢占，避免多个窗口重复遍历同一批 provider JSONL。
- **Omp 保留原生恢复边界。** Omp discovery、`omp --resume <id>`、远端 authoritative JSONL 删除仍可用。本版增加了三条 Omp fixture 的真实 WarpUI event-loop 验证，覆盖集合投影、搜索与 picker 生命周期；测试绝不触发 `omp --resume`。
- **普通本地 shell 不再伪装成可恢复 agent 历史。** Session Navigator 的 local live membership 只接受原生 agent 或 Ashide conversation 语义的 pane；相关 split、tab switch、reorder 和 active-selection 回归测试现通过真实 `PaneSessionBinding` 验证。
- **user-state 历史坐标清理受契约保护。** local 与 remote alias / pin sidecar 都会清理 `tab:*` 和 `*::source:tab:*` 旧布局身份，同时保留稳定 pane / durable agent 键。
