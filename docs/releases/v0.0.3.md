# Ashide v0.0.3

在 v0.0.2 基础上的试用构建，聚焦 Session Navigator Resume 主线程卡顿，以及配套的 local/remote materialization / 状态投影收敛。

## 修复

- **Resume 点击不再在 UI 热路径全量 snapshot 所有终端。** Session Navigator live 投影改为读取 `PaneConfiguration` / tab Environment（必要时做轻量 transport / conversation 查询），禁止 `PaneGroup::snapshot` 锁遍 `TerminalModel`。Activate / lifecycle action 只消费已提交的 `SessionNavigatorModel`；delivery 后只做一次 canonical Refresh + RestoreStarted。
- 去掉 lifecycle dispatch 内嵌的 speculative `session_navigator_action_model` Refresh，以及 `live_or_pending` 对全量 live 行的二次扫描。

## 改进

- Environment entry materialization 完成协议收敛到 `EnvironmentTable` 拥有的 typed outcome（Success / RetryableFailure / Cancelled / CarrierMissing），local/runtime 共用同一完成边界。
- Session Navigator 正交状态 badge（Restoring / Activity / FocusedLive / BackgroundLive）与相关 SPEC / static gate 同步。

## 平台范围

- macOS：本次构建产出 `Ashide-macos.dmg`，供本机试用 Resume 手感。
- Linux helper / Windows：随 release workflow 一并构建；本版本不以全平台 GUI 手测为发布门禁。

## 已知边界

- Resume 仍包含开 tab / 起 PTY、`save_app` 与远程 materialize 后再 sync 的必要成本；本版本去掉的是「点一下就锁所有终端做重 snapshot」。
- live 投影的 `cwd` 优先 binding / Environment root，不一定是终端实时 pwd；fullscreen agent 的 `active_conversation_id` 不再从 TerminalModel 热路径读取。
- LR-190 GUI 实机采样仍待本 DMG 试用确认后标为 verified。
