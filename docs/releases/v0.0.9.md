# Ashide v0.0.9 — Session Navigator Hotfix

## 本版改动（相对 v0.0.8）

- 修复当前 Codex `response_item/message(role=user)` 会话无法提取真实用户首条消息、标题退化为 `Codex` 的问题。
- 修复 Session Navigator 点击 Rename 后 viewport 复用旧 projection、别名编辑器不可见的问题。
- 补齐本地与远端会话扫描 fixture、inline rename lifecycle 回归测试及静态门禁。

## 平台范围

- macOS：发布 `Ashide-macos.dmg`。
- Linux / macOS remote helper：由 release workflow 构建并发布 SHA-256 校验资产。
- Windows：由 CI 编译、打包、checksum 并发布 installer。
